# Assembly Programs

8086 assembly programs written for the Computer Organization and Assembly Language course.

## Contents

| File | Description |
|---|---|
| `Calculator.asm` | Menu-driven calculator for basic arithmetic |
| `Binary Convertor.asm` | Converts a number to its binary representation |
| `Assembly_Project.asm` | String input and processing, the semester project |

## Running

The programs use `emu8086.inc` and are written for the **emu8086** emulator. Open a file in emu8086, then click **Emulate** and **Run**.
